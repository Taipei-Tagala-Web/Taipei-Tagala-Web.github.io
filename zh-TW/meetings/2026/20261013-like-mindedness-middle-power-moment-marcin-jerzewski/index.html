第227次例會 2026.10.13（二） 例會

在中等強國的時代，理念相近能走多遠？

Marcin Jerzewski 葉皓勤 歐洲價值安全政策中心（European Values Center for Security Policy）在台辦事處主任

臺灣與歐洲經常以「理念相近夥伴」形容彼此。民主、自由、人權等共同價值，確實讓雙方有了合作的基礎；但當價值遇上經濟利益、國內政治變化與對中關係，「理念相近」能不能進一步成為穩定而有韌性的夥伴關係？

本次例會邀請歐洲價值安全政策中心（European Values Center for Security Policy）在台辦事處主任 Marcin Jerzewski 葉皓勤，從2026年的國際局勢出發，帶我們重新檢視臺灣與歐洲的關係。

本次例會將探討

  • 台歐關係的現況：地緣競爭加劇下，中等強國如何深化合作？
  • 理念相近的現實挑戰：當共同價值遇上經濟利益、國內政治變化與對中關係
  • 整合性外交的可能性：從捷克、立陶宛案例看台灣與歐洲建立更具韌性的夥伴關係
